# 双手抓框探头

用于 Windows 桌宠 0.4.1 的自动边缘收纳。两种 Q 版 × 五套服装，各有一张专用抓框姿势，共 10 张，使用内置 image_gen 生成。

角色面部保持近乎直立，身体侧身藏在左边界后，短脖子、领口与少量肩胸自然露出，双手上下抓住竖直边框。运行时把手指的外侧贴到屏幕左边缘；右侧通过镜像绘制。头颈肩、手臂与袖口来自同一张连续姿势图，没有拼接或旋转站姿头部。
